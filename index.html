Stand it up in Grok Bot

Three bots. One shared thread. You approve every application.

  1. Create Cleared Scout and paste Prompt 1 plus the card-format rules.
  2. Create Hidden Gem Scout and paste Prompt 2 plus the same card rules.
  3. Create Application Strategist and paste Prompt 3.
  4. Open one chat named Job Pipeline. Hunters post cards there. You triage.
  5. Send survivors to the strategist one job at a time. Apply the same day. Ping. D3/D7 follow-up.
