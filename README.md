# Job Pipeline Lab

Interactive site for a three-bot job hunt.

## Open it

- Live file: `index.html`
- GitHub Pages (after you enable it): https://anthony0rt3ga501.github.io/job-pipeline-lab/

## Pages on the site

1. **Walkthrough** — click stages or press Play. Pick a voice from the menu (voices come from the visitor's browser).
2. **Build yours** — enter profile + optional résumé. Generates hunter and strategist prompts. Nothing is uploaded.
3. **Prompts** — setup order for Grok Bot.
