# How to run the bots

1. Create **Cleared Scout** in Grok Bot. Paste Prompt 1 from the site plus card-format rules.
2. Create **Hidden Gem Scout**. Paste Prompt 2 plus the same card rules.
3. Create **Application Strategist**. Paste Prompt 3 and the résumé facts.
4. One shared thread named Job Pipeline.
5. Morning hunt → 15-minute triage → strategist → apply same day → D3/D7 follow-up.

Never submit an application without a human yes.
